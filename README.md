# Quiz Game

A simple command-line Ture/False quiz game built with Python. 

This project demonstrates the fundamentals of OOP, working with multiple Python modules, classes, loops, and user input.

## Features
* Presents a series of true/false questions
* Accepts user input for each question
* Checks answers and provides immediate feedback
* Tracks the user's score throughout the quiz
* Displays the final score once all the questions have been answered

## Concepts practised
* OOp
* Classes and objects
* Constructors
* Methods
* Working with lists and dictionaries
